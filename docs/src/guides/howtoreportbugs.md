### How to report a bug you found
- Before reporting a bug, make sure you are actually on the latest version of the rom. You can find the latest version from https://www.hackdex.app/hack/soulgold.
- Additionally make sure that you are using one of the emulators listed under "Supported emulators" on the hackdex page. I won't take bug reports from potentially inaccurate emulators.
- If the two above criteria are checked, you can report the bug in the discord for the hack OR open an issue report https://github.com/Eemeliri/soulgold/issues
